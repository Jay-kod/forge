# FORGE — UI Design System

**Document version:** 1.0  
**Date:** 2026-09-01  
**Status:** DRAFT  

---

## 1. Design Philosophy

FORGE looks premium because of **precision, restraint, and information hierarchy** — not because of gradients, glow, or animation.

Every visual element must have a purpose. If it doesn't communicate information, guide attention, or improve usability, it doesn't belong.

---

## 2. What FORGE Does NOT Look Like

- An AI chatbot interface
- A dashboard full of cards with gradient headers
- A generic SaaS template with purple-to-blue hero sections
- An interface covered in Lucide icons and glassmorphism
- A design that screams "I was generated by an AI coding tool"

## 4. Typography

### 4.1 Font Stack

```css
:root {
    --font-display: 'DM Sans', system-ui, sans-serif;
    --font-body: 'Inter', system-ui, sans-serif;
    --font-code: 'JetBrains Mono', 'Fira Code', monospace;
}
```

**Rationale:** DM Sans for display/headings provides a distinctive geometric character without being the overused Inter-everywhere look. Inter for body text is the readability workhorse. JetBrains Mono for code blocks.

## 9. Accessibility Requirements

- **Color contrast:** WCAG AA minimum (4.5:1 for text, 3:1 for large text)
- **Focus indicators:** Visible, consistent focus rings on all interactive elements
- **Keyboard navigation:** All features accessible via keyboard
- **Screen reader:** Semantic HTML, ARIA labels where needed
- **Reduced motion:** Respect `prefers-reduced-motion`
- **Form labels:** Every input has an associated label
- **Error messages:** Announced to screen readers, visually prominent
- **Touch targets:** Minimum 44×44px on mobile

## 10. Semantic Color Usage

| Color | Use For | Never Use For |
|---|---|---|
| **Brand (Indigo)** | Primary actions, navigation, brand elements | Success states, data visualization |
| **Growth (Emerald)** | Success, positive outcomes, growth indicators, opportunities | Navigation, brand elements |
| **Attention (Amber)** | Warnings, important notices, assumptions | Errors, success, navigation |
| **Critical (Red)** | Errors, destructive actions, critical risks | Warnings, brand elements |
| **Neutral** | Surfaces, text, borders, secondary elements | Status indicators |
